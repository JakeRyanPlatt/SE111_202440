# Green Robot

Green Robot is the cleaned-up final project from the original class repository, now rebuilt as an Angular app running on Node.js.

## Requirements

- Node.js
- npm

## Install

```bash
npm install
```

## Run locally

```bash
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Build

```bash
npm run build
```

Build output is generated in `dist/`.
